# 排障

## 1. 无法生成配对码

**症状**：点击“生成配对码”后提示无法连接信令服务。

检查：
1. 信令是否运行：`curl http://127.0.0.1:5180/healthz`。
2. 设置中的地址是否与信令监听一致（默认 `ws://127.0.0.1:5180/ws`）。
3. 跨设备时不能使用 `127.0.0.1`；改为主机局域网 IP。
4. Windows 防火墙是否允许 TCP 5180 入站。
5. 生产使用 `wss://` 时证书是否受信任（客户端不会跳过证书校验）。

信令日志会记录 `signaling_connection_opened / signaling_auth_failed` 等事件，不记录配对码或 SDP。

## 2. 配对码无效 / 已锁定

- 配对码 6 位，默认 5 分钟有效，且只可成功使用一次。
- 连续输错 5 次会冷却 60 秒；同一 IP 5 分钟内错 30 次会封禁 5 分钟。
- 确认没有把“加入”和“创建”弄反：宿主生成码，加入方输入。
- 时间偏差过大会导致认证失败（允许 ±2 分钟）。

## 3. 对方加入后一直“等待确认”

- 宿主默认需要手动确认；确认弹窗可能在其他页面之上，检查应用窗口。
- 宿主在设置中关闭了“配对时需要本机确认”时会自动接受。
- 网络断开或宿主进程退出会由服务端清理会话，加入方会看到错误。

## 4. 连接建立但没有画面

- Windows 端：确认已在“屏幕共享”页选择采集源并点击“开始共享”。仅建立会话不会自动发送画面。
- Android 端：必须点击“共享我的屏幕”并在系统对话框授权。
- 采集源可能被关闭/最小化：窗口采集在窗口关闭时失效；重新选择采集源。
- 受 DRM/安全保护的窗口可能黑屏，这是平台限制。
- 检查防火墙是否阻止 UDP 媒体端口（SIPSorcery 使用动态端口范围）。
- 查看性能监控/日志中的 ICE 与连接状态；若 RTP 有发送但无接收，可能是防火墙。

## 5. IPv6 连接失败

- `仅 IPv6` 需要全局单播地址；链路本地（fe80::）不能当作公网地址。
- 许多家庭网络只分配 IPv6 前缀给路由器，未下发给设备。
- 切换为“自动”或“IPv4 优先”验证是否网络问题。
- 本版本未在 IPv6-only 环境实测；不要据此判断协议栈实现本身。

## 6. 局域网找不到设备

- 多播可能被 Windows 防火墙、路由器“客户端隔离”、企业 Wi-Fi 策略丢弃。
- 确认两端都开启局域网发现。
- Windows 防火墙首次运行可能需允许专用网络。
- Android 需允许 Wi-Fi 多播（应用已持有 MulticastLock）。
- VPN 可能改变默认路由/接口。
- 自动发现失败不影响通过配对码连接（但仍需要信令服务）。

## 7. TURN

- 仅中继模式必须配置至少一个 TURN，否则设置校验失败。
- TURN 凭据错误会表现成 ICE 失败；日志不会打印凭据。
- 未实测 TURN；若需要严格 NAT 环境，请先用标准 TURN 工具验证服务器。
- `turn:` 与 `turns:` 的传输/TLS 配置需与服务器一致。

## 8. Windows 采集失败

- `CAPTURE_ITEM_FAILED`：窗口/显示器已关闭或句柄失效。
- `CAPTURE_START_FAILED`：D3D11/WGC 初始化失败；更新显卡驱动，避免在受限远程会话中运行。
- 多显示器环境：选择“显示器 N”；窗口采集仅列出可见、非最小化、非工具的窗口。
- 分辨率变化/热插拔后请重新选择采集源（当前未完全自动重建）。

## 9. 性能问题

- 软件 VP8 在 1080p60 下 CPU 占用高。降到 1080p30/720p，或降低码率。
- 编码耗时持续 > 30 ms 表示 CPU 不足；观察“性能监控”。
- 不要用全屏 4K 采集去测试低端设备。
- 预览写入是节流的；但关闭窗口/最小化可进一步降低 UI 负载。
- 当前未实现硬件编码和自适应码率，网络拥塞时不会自动下采样；需要人工降低设置。

## 10. Android 问题

- Android 14+ 必须在前台服务中运行 MediaProjection；应用已按此实现，但未在真机验证。
- 拒绝通知权限可能导致前台服务启动异常（Android 13+ 会先请求通知权限）。
- 系统“停止共享”后应用应显示已连接但未共享；如果通知没有消失，请手动停止服务/退出应用（已知需真机复核）。
- 模拟器访问宿主机信令使用 `10.0.2.2`。
- 明文 `ws://` 依赖 Manifest 中的 `usesCleartextTraffic=true`；生产请改 `wss://` 并收紧。

## 11. 重置

- Windows：关闭应用，备份/删除 `%LOCALAPPDATA%\LinkView\settings.json`。删除 `identity.key` 会更换设备身份（需要重新配对）。
- Android：系统设置中清除应用数据会同时清除身份与已保存 TURN 凭据。

## 12. 日志与诊断

- Windows：设置 → 日志与诊断；可复制单条日志或导出诊断报告。
- Android：设置 → 日志；可分享诊断报告。
- 报告不包含屏幕内容、SDP 正文、配对码或凭据。
